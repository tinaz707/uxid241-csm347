# How do I run this project locally?
First download the project code and place the folder into your local server's 'htdocs' folder. To open it, run either XAMPP or MAMP and start Apache and MySQL. Create a new database for this project and import uxid241.sql into the database to create the required tables and data. Copy config.example.php and change it to config.php. Open the config.php and enter the credentaisl of your local database. Finally open the project through localhost in your web browser.
